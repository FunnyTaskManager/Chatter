Аддон для копирования и настройки чата.

- Легкое копирование ссылок (клик по ссылке).
- Копирование всего чата (ПКМ по окну чата и "Copy Text").
- Выделение сообщений, содержащих ключевое слово.
- Запоминание и легкий ввод ваших предыдущих сообщений.
- Множество опций для настройки чата.
